## 3. 作業手順(次セッションはこれに従う)

### 3-1. 素材の受け取り

- **PDFのテキスト抽出は使わない。** ふりがな付き縦組みが1文字ずつ分解されて崩れ、丸数字や問題文冒頭が欠落する。
- **PDFの画像化も使えない。** 実行環境に日本語フォントが無く、pdftoppmで変換すると罫線だけで文字が消える。
- 図表はユーザーからスクリーンショットで受け取る。
- **アップロードは1通1枚ずつ。** 同名ファイル(FullSizeRender.jpeg等)は連続で送られると上書きされ、前の1枚が消える。届いた時点で即 `cp` して別名保存すること。

### 3-2. INSERT文の書き方

- **長文はドル引用符 `$q$ … $q$` で囲む。** シングルクォート囲みだと文中の記号で `unterminated quoted string` エラーになる。
- MCPのexecute_sqlは権限エラーで使用不可。SQL文を提示してユーザーがSupabase SQL Editorで実行する。
- 5問程度ずつ区切って出す。1回で全問出すとレスポンスが切れる。
- 図表が必要な問題は `needs_image=true`、2枚必要なら `needs_image2=true` も指定。指定漏れはアップロード一覧に出ない。

### 3-3. 記述式(essay)の model_answer

4部構成:

1. `【解答例】` … 実際に解答用紙に書ける文章。ふりがなは `<ruby>漢字<rt>よみ</rt></ruby>`
2. `【1】法令・数値の根拠` … 条文・数値・工程表からの読み取り根拠
3. `【2】他に書ける切り口(引き出し)` … 本番で「異なる内容を複数」書く条件をクリアするため5〜8個
4. `【失点に注意】` … その設問固有の除外条件に抵触するNG例を列挙

除外条件は年度・設問ごとに異なるので、必ず設問文から拾って反映する。
令和7年度問題1の例:必要としない工種、品質が低下する変更、(解体を除き)建築設備工事。
令和7年度問題2の例:使用資機材の選定、記号c・m以外での作業上の安全。

### 3-4. 四肢択一(choice)の explanation

- 冒頭に `正解:④ 語句` を明記
- 選択肢1つずつ、なぜ正/誤かを説明。誤りの肢は「それが何なのか」も定義する
- 専門用語にはrubyでふりがな
- 最後に `【覚え方】` `【関連数値】` `【区別のしかた】` などで周辺知識を追加
- shuffle_choices は使わない(false のまま)

### 3-5. 登録後の確認

```sql
SELECT theme, count(*)
FROM questions
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 第二次検定'
GROUP BY theme
ORDER BY min(question_no);
```

重複が出た場合、attemptsテーブルがquestions.idを外部キー参照しているため、先にattemptsを削除してからquestionsを削除する。
