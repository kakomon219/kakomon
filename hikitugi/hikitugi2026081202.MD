## 3. 作業手順

### 3-1. 素材の受け取り

- **PDFを直接アップロードしてもらう。** 令和5・6年度はPDFのテキストが読める状態で届き、問題文の転記に使えた。
- ただし一部の設問文・法文名・選択肢が欠落することがある。**届いたテキストを通読して欠落箇所を洗い出し、その部分だけスクリーンショットを依頼する。** 令和5年度では問題5-Aの5.、問題5-Cの3.、問題5-Bの4.の分数選択肢、問題1の冒頭一文が欠落していた。
- **図表(工程表・出来高表・工事概要・用語一覧表)は必ずスクリーンショットで受け取る。** PDF中では画像であり、テキストとして取れない。
- **送られてきた資料が対象年度・対象級のものか、冒頭で必ず確認する。** 過去に一級のPDF、別年度の工程表が混ざって届いた。表紙の級・年度、月の列数、記号の位置で判別する。

### 3-2. INSERT文の書き方

- **長文はドル引用符 `$q$ … $q$` で囲む。** シングルクォート囲みだと文中の記号で `unterminated quoted string` エラーになる。
- MCPのexecute_sqlは権限エラーで使用不可。SQL文を提示してユーザーがSupabase SQL Editorで実行する。
- **設問の塊(1.、2.、3.…)ごとに区切って出す。** 1問ずつでは細かすぎ、全問一度ではレスポンスが切れる。
- **次を出す前に、前の実行が完了したことを確認する。** 令和6年度で No.31〜34・36 が二重登録された。重複時は以下で復旧できる。

```sql
DELETE FROM questions
WHERE id IN (
  SELECT id FROM (
    SELECT id, row_number() OVER (PARTITION BY question_no ORDER BY id) AS rn
    FROM questions
    WHERE qualification = '建築施工管理技士二級'
      AND exam_round = '令和○年度 第二次検定'
      AND question_no IN (...)
  ) t WHERE t.rn > 1
);
