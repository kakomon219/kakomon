## 3. 作業手順

### 3-1. 素材の受け取り

- **PDFを直接アップロードしてもらう。** 令和4年度もPDFのテキストが読める状態で届き、問題文の転記に使えた。
- **届いたテキストを通読して欠落箇所を洗い出し、その部分だけスクリーンショットを依頼する。** 令和4年度で欠落していたのは以下。同じ箇所が他年度でも欠けやすい。
  - 各問題の柱書き一文(問題1・問題2・問題3の冒頭)
  - 工事概要の階数・面積などの数値
  - 設問中の「◯月末まで」の月次
  - 分数の選択肢(1/4・1/5・1/8・1/10 等)
  - 本文中の数値(「2本以上」「1本は」「ネジ1山から6山」「1回の塗り付け面積」等)
- **「◯月末まで」は絶対に推測しない。** 令和4年度は出来高表が4月末時点だったため設問も4月末と推測したが、実際は「1月末まで」だった。必ず問題用紙で確認する。
- **図表(工程表・出来高表・工事概要・用語一覧表・締付け順序図)は必ずスクリーンショットで受け取る。** PDF中では画像であり、テキストとして取れない。
- **送られてきた資料が対象年度・対象級のものか、冒頭で必ず確認する。** 表紙の級・年度、月の列数、工種ごとの金額で判別する。
- 同名ファイル(FullSizeRender.jpeg)は連続アップロードで上書きされるため、1通1枚ずつ送ってもらい、届いた時点で即別名保存する。

### 3-2. INSERT文の書き方

- **長文はドル引用符 `$q$ … $q$` で囲む。** シングルクォート囲みだと文中の記号で `unterminated quoted string` エラーになる。
- MCPのexecute_sqlは権限エラーで使用不可。SQL文を提示してユーザーがSupabase SQL Editorで実行する。
- **設問の塊(1.、2.、3.…)ごとに区切って出す。** 1問ずつでは細かすぎ、全問一度ではレスポンスが切れる。
- **次を出す前に、前の実行が完了したことを確認する。** 令和6年度で No.31〜34・36 が二重登録された。重複時は以下で復旧できる。

```sql
DELETE FROM questions
WHERE id IN (
  SELECT id FROM (
    SELECT id, row_number() OVER (PARTITION BY question_no ORDER BY id) AS rn
    FROM questions
    WHERE qualification = '建築施工管理技士二級'
      AND exam_round = '令和○年度 第二次検定'
      AND question_no IN (...)
  ) t WHERE t.rn > 1
);
```

- **登録済みの内容を直す指示は、必ず実行可能なSQL文で出す。** 令和4年度で「誤：〜／正：〜」という文章の修正指示を出してしまい、そのままSQL Editorに貼られて構文エラーになった。修正は次の形で出すこと。

```sql
UPDATE questions
SET model_answer = replace(model_answer, '修正前の文字列', '修正後の文字列')
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 第二次検定'
  AND question_no = ○;
```

- 図表が必要な問題は登録時に **needs_image=true** を設定する。指定し忘れると `/admin/upload` の一覧に出ない。

### 3-3. 登録後の確認

```sql
SELECT theme, count(*) AS 問数, min(question_no) AS 開始, max(question_no) AS 終了
FROM questions
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 第二次検定'
GROUP BY theme
ORDER BY min(question_no);
```

```sql
SELECT question_no, count(*)
FROM questions
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 第二次検定'
GROUP BY question_no
HAVING count(*) > 1;
```
