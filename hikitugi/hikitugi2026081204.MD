### 3-1. 出来高表に「記載していない工事」がある年度の解法

柱書きに「◯◯工事の工事金額及び出来高は記載していない」とある場合、各工種の工事金額の合計は総工事金額と一致する。その工種の工事金額から記載済みの月別出来高を差し引くと、隠された金額が出る。

- 令和3年度 … 耐火被覆工事は鉄骨工事900万円に含まれる。900−(1月30+2月780)=**90万円**
- 令和2年度 … 外部サッシ工事は建具工事400万円に含まれる。400−(5月予定100)=**300万円**

累計を問う設問では、この金額を足し忘れるのが最大の失点ポイント。設問(完了日を問う設問)と連動している。

## 4. 作業手順

### 4-1. 素材の受け取り

- **PDFを直接アップロードしてもらう。** 問題文の転記に使える。
- **届いたテキストを通読して欠落箇所を洗い出し、その部分だけスクリーンショットを依頼する。** 欠けやすいのは以下。
  - 各問題の柱書き一文(問題1〜5すべて)
  - 工事概要の階数・面積などの数値
  - 設問中の「◯月末まで」の月次
  - 分数の選択肢(1/2・1/3・2/3・1/4 等)
  - 本文中の数値(「1mmを超える」「5〜15秒」「2箇所以上」「ねじ◯山」等)
  - 法文の条項番号(第89条第◯項、第◯条 等)
- **「◯月末まで」は絶対に推測しない。** 令和4年度で出来高表が4月末時点だったため設問も4月末と推測したが、実際は「1月末まで」だった。必ず問題用紙で確認する。
- **図表(工程表・出来高表・工事概要・用語一覧表・締付け順序図)は必ずスクリーンショットで受け取る。** PDF中では画像でありテキストとして取れない。
- **送られてきた資料が対象年度・対象級のものか、冒頭で必ず確認する。** 表紙の級・年度・実施日、月の列数、工種ごとの金額で判別する。
- 同名ファイル(FullSizeRender.jpeg)は連続アップロードで上書きされるため、1通1枚ずつ送ってもらい、届いた時点で即別名保存する。2枚同時に送られると1枚しか残らない。

### 4-2. INSERT文の書き方

- **長文はドル引用符 `$q$ … $q$` で囲む。** シングルクォート囲みだと文中の記号で `unterminated quoted string` エラーになる。
- MCPのexecute_sqlは権限エラーで使用不可。SQL文を提示してユーザーがSupabase SQL Editorで実行する。
- **設問の塊(問題1、用語a〜e、問題3の1.…)ごとに区切って出す。** 1問ずつでは細かすぎ、全問一度ではレスポンスが切れる。4〜5問が目安。
- **次を出す前に、前の実行が完了したことを確認する。** 重複時は以下で復旧できる。

```sql
DELETE FROM questions
WHERE id IN (
  SELECT id FROM (
    SELECT id, row_number() OVER (PARTITION BY question_no ORDER BY id) AS rn
    FROM questions
    WHERE qualification = '建築施工管理技士二級'
      AND exam_round = '令和○年度 ○○'
      AND question_no IN (...)
  ) t WHERE t.rn > 1
);
```

- **登録済みの内容を直す指示は、必ず実行可能なSQL文で出す。** 「誤：〜／正：〜」という文章の修正指示は不可。

```sql
UPDATE questions
SET model_answer = replace(model_answer, '修正前の文字列', '修正後の文字列')
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 ○○'
  AND question_no = ○;
```

- 図表が必要な問題は登録時に **needs_image=true** を設定する。指定し忘れると `/admin/upload` の一覧に出ない。

### 4-3. 登録後の確認

```sql
SELECT theme, count(*) AS 問数, min(question_no) AS 開始, max(question_no) AS 終了
FROM questions
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 ○○'
GROUP BY theme
ORDER BY min(question_no);
```

```sql
SELECT question_no, count(*)
FROM questions
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 ○○'
GROUP BY question_no
HAVING count(*) > 1;
```

**theme別の問数と開始・終了番号まで必ず見ること。** 令和2年度は重複0でも「正誤指摘(建築) 8問・26〜29」と範囲が不自然で、No.26〜29の二重登録とNo.30〜33の未登録が同時に起きていた。問数だけ、あるいは重複だけを見ていると気付けない。

### 4-4. 画像アップロード

同一画像を複数問に紐付ける方法は2通り。**オーナーの指示に従う。**

1. `/admin/upload` から問題ごとに個別アップロード(令和3年度はこの方式)
2. 代表1問にアップロードし、そのimage_urlをUPDATEで他問にコピー(令和2年度はNo.20にアップ後、他5問へコピー)

```sql
UPDATE questions
SET image_url = (
  SELECT image_url FROM questions
  WHERE qualification = '建築施工管理技士二級'
    AND exam_round = '令和○年度 ○○'
    AND question_no = ○
)
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 ○○'
  AND question_no IN (...);
```

工程表と出来高表が1ページに収まっている年度は、問題3の全問が同じ1枚を参照する。

## 5. 今回のセッションで発生した不具合

| 事象 | 対策 |
|---|---|
| 令和2年度 No.26〜29が二重登録、No.30〜33が未登録 | DELETE+再INSERTで復旧。確認SQLはtheme別の開始・終了番号まで見る |
| 解説文にキリル文字「а」が混入(令和2年度 No.6) | UPDATE replaceで修正済み |
| HTMLタグの閉じ忘れ `</shrong>`(令和2年度 No.11) | UPDATE replaceで修正済み |

登録直後に以下で機械的に検出できる。

```sql
SELECT question_no
FROM questions
WHERE qualification = '建築施工管理技士二級'
  AND exam_round = '令和○年度 ○○'
  AND (model_answer LIKE '%</shrong>%'
       OR model_answer ~ '[а-яА-Я]'
       OR explanation LIKE '%</shrong>%');
```
